## 2. Arbeidsdeling i `BOKKANDIDATER/`

* **`FERDIGE_PROSJEKTER/` (denne mappen):** Fullt ferdigstilte, satte og eksporterte verk klare for forlag og lesing.
* **`GRUNNLAGSTEKSTER_OG_MONOGRAFIER/`:** Aktive kildetekster, nye filosofiske traktater og levende monografier under utvikling.
* **`NOTEBOOKLM_SYNTESER/`:** Kunnskapsbrønner og dype tverrfaglige synteser.
